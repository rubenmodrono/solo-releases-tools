Conecta tu cuenta

Solo hace falta una vez. Vas a crear una "llave" en Azure DevOps para que esta página pueda ver tus tareas y subir tus archivos.

  1. Abre esta página de Azure DevOps y pulsa New Token.
  2. En Name escribe Subidas. En Expiration elige la fecha más lejana que te deje.
  3. En Scopes, pulsa Show all scopes y marca:
    • Code: Read & write
    • Work Items: Read & write
    • Project and Team: Read
  4. Pulsa Create, copia la llave y pégala aquí abajo.

La llave se queda guardada solo en este navegador.
